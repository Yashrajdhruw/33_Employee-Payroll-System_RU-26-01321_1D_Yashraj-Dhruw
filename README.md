# Employee Payroll System

## Overview
The Employee Payroll System automates salary processing and employee pay record management.
It calculates basic pay,allowance, and deductions to generate accurate net salary figures while reducing manual calculation errors.

## Repository Structure
- **'Codebase/'**: Contains the main source and sample inputs used to verify system accuracy.
- **'Testcase/'**: Contains test cases and sample inputs and used to verify system accuracy.

## How to Run
1. Download or clone this repository to your local machine.
2. Open the 'Codebase' folder in your IDE or terminal.
3. Compile and execute the main source file
4. Enter employee details when prompted, or use the sample inputs provided in the 'Testcase' folder to verify the output.
